# 画面録画（Windows アプリ）

パソコンの画面と音声を録画し、MP4 で保存するシンプルなデスクトップアプリです（Electron 製）。

## 機能
- 画面全体またはウィンドウを選んで録画
- システム音声（PCの音）とマイク音声を録音（ミックスして1本に）
- 一時停止・再開
- 停止すると保存先を聞かれ、MP4（H.264 + AAC）に変換して保存
- 録画中のデータはディスクに書き出すので、長時間でもメモリを圧迫しません

## インストーラーの入手
GitHub の Actions タブで「Build Windows installer」を実行（または push）すると、Artifacts から `installer` をダウンロードできます。中の `.exe` を実行してインストールします。

## 自分でビルドする（Windows）
```
npm install
npm start        # 開発用に起動
npm run dist     # dist/ にインストーラーを作成
```
Node.js 20 以上が必要です。MP4 変換用の ffmpeg は同梱されるため、別途インストールは不要です。

## 補足
- システム音声の録音は Windows の loopback 機能を使うため、録画中に鳴っている音がそのまま録れます。
- インストーラーには署名がないため、初回は Windows SmartScreen の警告が出ることがあります。

# Belajar! インドネシア語入門アプリ（`indonesia/`）

あいさつ・単語・会話をゲーム感覚で学べる、初心者向けのインドネシア語アプリです。インストール不要のWebアプリ（PWA）で、スマホにもホーム画面追加できます。

## 遊び方
```
cd indonesia
python3 -m http.server 8000   # → http://localhost:8000 を開く
```
`indonesia/index.html` を直接ブラウザで開いても動きます（オフライン対応のPWA機能はhttp(s)配信時のみ）。

## 学べる内容（6ユニット・約75フレーズ）
あいさつ／自己紹介／数字／食べ物・注文／買い物・移動／日常会話

出題形式：4択・逆引き4択・聞き取り（端末にインドネシア語の音声がある場合）・単語並べ替え・スペル入力・ペアマッチ・会話の返事選び

## 続けたくなる仕掛け
- 🔥 **ストリーク**（連続日数）と、途切れそうな時の警告、🧊 ストリークフリーズ
- 🎯 **デイリー目標**のリングと「あとXP」表示、🎁 達成で開く**ランダム宝箱**
- ⚡ **コンボ**でXPが増え、効果音・紙吹雪・バイブで即フィードバック
- 🎰 レッスン後の**ラッキーボーナス**（確率でXP×1.5〜3）
- 📜 毎日変わる**クエスト**、🏅 **バッジ**、⭐ レベルと称号、★5冠のユニット進捗
- 🔁 **間隔反復の復習**（忘れかけた頃に出題）

学習データはブラウザの localStorage に保存されます（サーバー送信なし）。
