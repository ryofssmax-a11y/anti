# 画面録画

パソコンの画面と音声を録画する、ブラウザだけで動くシンプルなアプリです。インストールは不要です。

## 使い方

1. `index.html` を Chrome または Edge で開きます。または `python3 -m http.server` を実行して `http://localhost:8000` を開きます。
2. 録音したい音声を選びます。
   - システム音声: 共有した画面やタブの音
   - マイク音声
3. 「録画開始」を押し、共有する画面・ウィンドウ・タブを選びます。システム音声を録るには、ダイアログで「音声も共有」にチェックを入れます。
4. 「停止」を押すとプレビューが出るので、「ダウンロード」で保存します（`.webm` 形式）。

一時停止と再開もできます。

## 注意

- システム音声の対応状況は OS とブラウザで異なります。Windows は画面全体またはタブ、Mac はタブのみです。
- 録画データはすべてブラウザ内で処理され、外部に送信されません。
