# eBayせどり管理（Windows アプリ）

ヤフオク・メルカリなど国内の中古売買サイトで仕入れ、eBay で販売する「輸出せどり」を管理するデスクトップアプリです（Electron 製）。
利益が出そうな商品のピックアップから、日々の販売記録、月ごとの損益管理までをひとつにまとめています。

## スマホ版（PWA）

同じアプリをスマホでも使えます。インストールはストアを通さず、ブラウザから行います。

**URL: https://ryofssmax-a11y.github.io/anti/**

- **iPhone**：Safari で URL を開く → 共有ボタン（□↑）→「ホーム画面に追加」
- **Android**：Chrome で URL を開く → メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」

ホーム画面のアイコンから起動すると、全画面のアプリとして動きます。一度開けば電波のない場所でも起動できます。

スマホ版の注意点：
- **eBay 相場の自動取得は使えません**（eBay がブラウザからの直接の問い合わせを受け付けないため）。「eBay 売却済み」ボタンで相場を確認して、価格を入力してください。それ以外の機能はすべて使えます。
- データはその端末のブラウザ内に保存されます。ブラウザのデータを消すと記録も消えるので、設定画面の「バックアップを保存」で定期的に保存してください（共有メニューから「ファイル」や Google ドライブに保存できます）。
- PC版とスマホ版でデータを移すときも、このバックアップファイルを「バックアップから復元」で読み込みます。
- iPhone では、ホーム画面に追加して使ってください。Safari のタブで開くだけだと、しばらく使わないとデータが消されることがあります。

### 公開のしかた（初回のみ）
1. `sedori/src` を変更して push するか、Actions タブで「Deploy eBay sedori PWA (GitHub Pages)」を実行すると、`gh-pages` ブランチに公開用ファイルができます。
2. GitHub のリポジトリ画面で **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を「gh-pages」「/ (root)」にして Save。
3. 数分後に上の URL で開けるようになります。以降は push するたびに自動で更新されます。

## 主な機能

| 画面 | できること |
|---|---|
| ダッシュボード | 今日の販売・今月の売上/純利益・目標達成率、在庫額、未発送の注文、利益候補トップ5、90日以上の長期在庫、直近12か月の純利益グラフ |
| リサーチ・利益計算 | キーワードから eBay（売却済み/出品中）・ヤフオク（落札相場）・メルカリ・ラクマ・Yahoo!フリマ・駿河屋・ハードオフ・セカストを一発検索。eBay API で相場（最安・中央値・平均）を取得し、**仕入れ上限価格**を自動計算。仕入れ値と販売予想価格を入れると手数料・送料・為替込みの利益/利益率/ROI を計算し、◎仕入れ候補 / △薄利 / ✕赤字 を判定 |
| 貼り付けで取り込み | メルカリ・ヤフオクなどで「共有 → コピー」した文章や商品ページの URL を貼り付けると、商品名・価格・URL・仕入れ先を読み取って利益シミュレーターに自動入力（ヤフオクは即決価格を優先） |
| バーコード読み取り | 📷ボタンで商品の JAN・ISBN・UPC をカメラで読み取り（写真から・手入力も可）。チェックデジットを検証し、Amazon・楽天・Yahoo!ショッピング・駿河屋・eBay・ヤフオク・メルカリを JAN でそのまま検索。同じ JAN の在庫や過去の販売実績があれば表示。PC版の eBay 相場取得は JAN の完全一致で検索 |
| ウォッチリスト | 狙っている商品のキーワードを登録し、eBay 相場から「この金額以下なら買い」の上限価格を表示。「全サイトで探す」で仕入れ先を一括検索 |
| 在庫・販売管理 | 仕入れ登録（SKU 自動採番・カテゴリ・保管場所）→ 出品中 → 売却済 → 発送済 のステータス管理。「売れた」ボタンで販売価格・実送料・為替を記録し利益を確定。購入者・追跡番号・メモも管理 |
| 月次レポート | 月ごとの売上・eBay手数料・入金コスト・仕入原価・国際送料・粗利益・経費・純利益・粗利率・仕入れ額。日別の売上と販売明細、輸出消費税の還付見込額。CSV 出力 |
| まとめ仕入れ | 1回の購入で複数の商品を仕入れたとき、総額と送料を想定販売価格の比率（なければ均等）で各商品に按分して一括登録 |
| 返品・返金 | 購入者への返金額と返品送料などの損失を記録し、商品ごとの利益と月次集計に反映 |
| 分析 | 仕入れ先別・カテゴリ別の利益、1点あたり利益、利益率、ROI、販売率、平均販売日数。ダッシュボードには直近90日の回転日数を表示 |
| 確定申告用 | 年ごとの売上原価（期首棚卸高 ＋ 当期仕入高 − 期末棚卸高）を自動計算し、CSV で出力 |
| 経費 | ストア月額・梱包資材などの経費を登録し、純利益に反映 |
| 設定 | 為替レート（起動時に自動取得）、手数料率、利益判定の基準、月の目標、eBay API キー、バックアップ/復元 |

## まず画面を見てみたいとき
設定画面の「デモデータを読み込む」を押すと、約1年分の仕入れ・販売・経費のサンプルが入り、すべての画面の表示を確認できます。デモ中は画面上部に案内が出ます。実際に使い始めるときは「すべてのデータを消去」で消してください（設定は残ります）。

## 利益の計算方法

```
売上(USD)   = 販売価格 + 購入者負担送料
eBay手数料  = 売上 × (落札手数料% + 海外決済手数料% + 広告費%) + 1注文あたりの固定手数料
入金コスト  = (売上 − eBay手数料) × 為替 × 入金・為替コスト%
利益(円)    = (売上 − eBay手数料) × 為替 − 入金コスト − 仕入れ価格 − 国内送料 − その他費用 − 国際送料
```

- 手数料率の初期値は目安です。カテゴリやストア契約によって変わるので、**設定画面でご自身の条件に合わせてください**。販売記録では eBay の手数料実額を入力することもできます。
- 「仕入れ上限価格」は、最低利益（初期値 3,000円）と最低利益率（初期値 15%）の両方を満たせる仕入れ総額の上限です。
- 輸出消費税の還付（仕入れ価格の 10/110）は、設定で利益に含めるかどうかを選べます。

## eBay 相場の自動取得（任意）

1. [eBay Developers Program](https://developer.ebay.com/) に登録（無料）
2. Application Keys で **Production** の Keyset を作成
3. 設定画面に Client ID（App ID）と Client Secret（Cert ID）を入力

取得できるのは Browse API の「出品中」の価格です。実際に売れた価格は「eBay 売却済み」ボタンで必ず確認してください。
API キーがなくても、各サイトの検索ボタンと手入力で全機能を使えます。

### ヤフオク・メルカリの自動取得について
ヤフオク・メルカリ等には個人が使える公開 API がなく、自動収集（スクレイピング）は各サイトの利用規約で禁止されています。
そのためこのアプリでは、検索ページをワンクリックで開き、見つけた商品の価格を入力すると即座に利益判定する方式にしています。

## データの保存場所
すべてのデータはパソコン内（`%APPDATA%\ebay-sedori-manager\sedori-data.json`）に保存され、外部には送信されません（為替レート取得と eBay API への問い合わせを除く）。設定画面からバックアップ（JSON）を定期的に保存してください。

## インストーラーの入手
GitHub の Actions タブで「Build eBay sedori app (Windows)」を実行（または `sedori/` を変更して push）すると、Artifacts から `sedori-installer` をダウンロードできます。

## 自分でビルドする（Windows）
```
cd sedori
npm install
npm start        # 開発用に起動
npm test         # 利益計算のテスト
npm run dist     # dist/ にインストーラーを作成
```
Node.js 22 以上が必要です。`src/index.html` をブラウザで直接開いても動作を確認できます（データはブラウザに保存され、eBay API・為替取得は使えません）。
