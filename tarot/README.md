# 星読みタロット（Webアプリ）

毎日の「今日の1枚」と、Claude による AI リーディングを組み合わせたタロット占いアプリです。

## 機能
- **今日の1枚**: 1日1回カードを引いて短いメッセージを表示。連続日数を記録
- **占う**: 質問を入力 → スプレッドと占い師の口調を選ぶ → シャッフル → 22枚から直感で選ぶ → めくる → AI がリーディング
  - スプレッド: ワンオラクル / スリーカード / 二択 / ケルト十字
  - 占い師: 神秘の占い師 / やさしい友だち / ロジカルなコーチ
  - リーディング後にチャットで追加質問（最大10回）
- **記録**: 引いたカードの統計（よく出るカード・スートの割合・逆位置率）、過去のリーディングの閲覧と続きの質問
- 78枚フルデッキ、逆位置のあり/なし切り替え
- 記録はブラウザ（localStorage）に保存されます

## 構成
| 場所 | 内容 |
|---|---|
| `src/` | 画面（React + Vite） |
| `server/index.ts` | API サーバー（Express）。Claude API を呼んで結果をストリーミングで返す |
| `shared/` | カードデータ・スプレッド・占い師の設定・AIへの指示（画面とサーバーで共通） |
| `scripts/build-artifact.mjs` | claude.ai のアーティファクト用に1ファイルへまとめる |

API キーはサーバー側だけで使い、ブラウザには渡しません。AI へのプロンプトはサーバーがカードIDから組み立てます。

## 動かし方
Node.js 20 以上が必要です。

```
cd tarot
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # Claude API のキー
npm run dev                           # http://localhost:5173 で開く
```

本番用:
```
npm run build
npm start      # http://localhost:8787 で画面と API の両方を配信
```

### claude.ai のアーティファクトとして公開する
```
npm run build:artifact   # dist/artifact.html（CSSとJSを埋め込んだ1ファイル）を作る
```
アーティファクトとして開くと、AIリーディングは閲覧者自身の Claude（`sample` 機能）で動きます。APIキーもサーバーも不要です。

### 環境変数
| 変数 | 既定値 | 説明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | （必須） | Claude API のキー |
| `TAROT_MODEL` | `claude-opus-5-5` | 使うモデル |
| `PORT` | `8787` | サーバーのポート |

## AI まわりの設定
- モデルは `claude-opus-5-5`、応答速度を優先して `effort: "low"`
- 安全上の理由で応答が断られたときに別モデルで再試行するサーバー側フォールバック（`fallbacks: "default"`）を有効化
- 使いすぎ防止のため、1つのIPにつき10分で30回までに制限
