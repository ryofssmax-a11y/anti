# 馬券収支電卓（MVP）

馬券の買い目を計算して、そのまま収支に記録するスマホアプリです（Flutter 製、iOS / Android）。

## できること
- **買い目計算**：単勝・複勝・枠連・馬連・ワイド・馬単・3連複・3連単・WIN5。通常・ボックス・ながし（軸1頭/2頭、着順固定、マルチ）・フォーメーション。取消馬の除外
- **オッズと資金配分**：合成オッズ、トリガミ判定、均等払戻・目標払戻・傾斜配分
- **収支記録**：計算結果をワンタップで記録。簡易記録（投資額と払戻額だけ）
- **結果入力と一括判定**：着順（同着対応）と払戻金を入れると、そのレースの全買い目を判定。取消は返還
- **分析**：期間別（今日・今週・今月・今年・全期間・期間指定）の回収率・的中率・最大連敗・最高払戻、累積収支グラフ、券種・買い方・競馬場・購入方法別の回収率
- **その他**：月別一覧とカレンダー、予算上限アラート（80%・100%）、買い目テンプレート、CSV 書き出し・読み込み、20歳以上の確認

記録は端末の中（SQLite）にだけ保存し、外部には送信しません。

## MVP で入れていないもの
レース結果・オッズの自動取得、QR コード読み取り、クラウド同期、課金と広告。課金がないため、仕様書で有料としていた機能（資金配分など）もすべて使えます。

## Android 版（APK）の入手
GitHub の Actions タブで「Build baken-app (Android APK)」を開き、最新の実行の Artifacts から `baken-app-apk` をダウンロードします。中の `app-release.apk` をスマホに入れてインストールします（提供元不明のアプリの許可が必要です）。

この APK はテスト用の署名で作っています。Google Play に出すときは、自分の署名鍵を用意してください。

## 自分でビルドする
```
cd baken-app
flutter pub get
flutter test           # テスト
flutter run            # 実機・エミュレーターで起動
flutter build apk      # Android
flutter build ipa      # iOS（Mac と Apple Developer アカウントが必要）
```

## 構成
| 場所 | 内容 |
| --- | --- |
| `lib/core/` | 買い目の展開・点数、合成オッズ・資金配分、的中判定（Flutter に依存しない純粋な Dart） |
| `lib/data/` | SQLite への保存、集計、CSV、設定 |
| `lib/ui/` | 画面（ホーム・記録・計算・分析・設定） |
| `test/` | 点数の全パターン照合、判定、DB、画面の通し操作のテスト |
