# Real Talk English

ネイティブが実際の会話でよく使う英語フレーズを、楽しく身につけるための Web アプリです。
インストール不要で、`index.html` をブラウザ（スマホでも可）で開くだけで動きます。

## 機能
- **今日のフレーズ**：毎日1つ、「教科書っぽい英語 → ネイティブの言い方」の比較・ニュアンス解説・会話例つきで紹介
- **フレーズ図鑑**：70 フレーズ（あいさつ／あいづち／気持ち／誘う・頼む／お礼・断り／仕事／日常／旅行）。検索・お気に入り・「覚えた」チェック
- **クイズ**：場面 → 英語、英語 → 意味、教科書英語を直す、苦手の復習（間違えたフレーズを自動で記録）
- **会話シミュレーション**：カフェ・週末の予定・職場・久しぶりの再会・ホテルのチェックイン・レストランの6シーン。選んだ返事が「ネイティブっぽい／惜しい／不自然」かを解説
- **話す（シャドーイング）**：収録済みのネイティブ風音声を聞いてまね、マイクで発音チェック（Chrome / Edge / Safari の音声認識を使用）
- **ゲーム要素**：XP・レベル・連続学習日数・1日の目標

学習記録はブラウザ（localStorage）に保存されます。

## フレーズや会話を増やすには
`index.html` 内の `PHRASES`（フレーズ）と `SCENES`（会話シーン）の配列に項目を追加してください。
`g` は意味のグループで、クイズで同じ意味の選択肢が並ばないようにするために使います。

## 音声について
`audio.js` に全フレーズ・会話の音声（Kokoro TTS で生成した MP3）が入っています。端末に読み上げ機能が無くても再生できます。
フレーズを追加して `audio.js` に音声が無い場合は、端末の読み上げ機能（Web Speech API）で再生します。
